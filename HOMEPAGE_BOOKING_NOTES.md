# Homepage stay estimator

The homepage estimator is informational only. It does not check live availability and it does not create a reservation.

## Rate periods

- Low season: September, October and November 2026.
- December 2026.
- January and February 2027.
- Holiday / Tet overrides: 01-02 January 2027 and 05-14 February 2027.

The estimated room charge is calculated for one room by summing the published nightly room rate for each night from check-in (inclusive) to check-out (exclusive). If any selected night is outside the published rate periods, the homepage asks the guest to contact Pinewood for rate confirmation instead of inventing a value.

## Booking request flow

`BOOK NOW / ĐẶT PHÒNG` opens the existing Contact page with the selected room type, dates, guest count, number of nights and estimated room charge carried in the URL. The Contact page then prepares a bilingual booking-request message for the guest to send by email or copy for another contact channel.

The booking request explicitly states that Pinewood must confirm room availability and the final rate.
