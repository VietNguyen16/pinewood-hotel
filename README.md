# Pinewood Hotel Dalat — Digital Guest Directory

Production-ready static website for Pinewood Hotel Dalat.

- Mobile-first responsive UI for smartphone QR access and desktop use
- Vietnamese source content with English translation
- Pinewood official logo and brand palette
- VI/EN language persistence via localStorage
- Session assistance popup, click-to-call Reception, official Zalo QR
- Static hash routing for GitHub Pages compatibility
- Future booking integration point in `js/config.js`

## GitHub Pages

Publish from the repository `main` branch, root folder. The included `CNAME` targets `pinewoodhotel.vn`.

Do not change DNS until GitHub Pages is enabled and the deployment URL is confirmed.
